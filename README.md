# Vorge — 個人用語彙・言語化トレーニングアプリ

語彙を増やし、思考・説明・文章・読解・議論の力を鍛えるための PC 向け学習アプリです。
設計の詳細は [docs/design.md](docs/design.md) を参照してください。

## 現在できること(第 4 段階まで)

- ホーム:今日の復習予定・今日の新規学習数・登録語彙数・各機能への入口
- フラッシュカード:「語彙 → 意味」「意味 → 語彙」の 2 モード、正解 / 自信がない / 不正解の自己採点、間隔反復による復習日の自動設定(復習予定を優先して出題)
- 学習履歴:連続学習日数、正答率の推移、日ごとの回答数グラフ、習得状況、今後7日の復習予定、苦手な語彙の一覧と集中練習
- 作文トレーニング:お題(日常・説明・意見/おまかせ)と文字数・使う語彙を選んで作文、自動チェック(語彙の使用・文字数・繰り返し・文末)、添削依頼文のコピー、作文の保存と読み返し、お題の追加・編集
- 語彙ライブラリ:キーワード / カテゴリ / 難易度での検索、一覧、詳細、追加、編集、削除
- CSV入出力:検証つきインポート(エラー行の行番号表示、ID重複のスキップ/上書き)、UTF-8 BOM付きでのエクスポート

## はじめての準備(初回のみ)

PowerShell でこのフォルダを開いて実行します。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

> `Activate.ps1` が「スクリプトの実行が無効」と言われたら、
> `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` を一度だけ実行してください。

## 起動方法

```powershell
.\.venv\Scripts\Activate.ps1
streamlit run app.py
```

ブラウザで http://localhost:8501 が開きます。終了はターミナルで `Ctrl + C`。

## 動作確認の手順

1. ホームに「ようこそ!」の案内が表示される(初回)
2. 「CSV入出力」→「同梱のサンプル語彙」を選び、検証結果が「200行 / エラー0」になることを確認 →「インポートを実行」
3. 同じ操作をもう一度すると「既存IDと重複 200」と警告され、スキップされることを確認
4. 「語彙ライブラリ」で行をクリック → 右に詳細カード。キーワード検索・カテゴリ・難易度の絞り込みを試す
5. 「編集」で内容を変えて保存 /「新規追加」タブで 1 語追加 /「削除」で確認ダイアログが出る
6. 「CSV入出力」→「エクスポート」で CSV をダウンロードし、Excel で文字化けしないか確認
7. 「フラッシュカード」→「学習をはじめる」→「答えを見る」→ 正解 / 自信がない / 不正解を押す。
   ボタンに次回の復習日(例:正解なら 3日後)が表示される
8. 「中断して結果を見る」で結果一覧が表示され、ホームの「今日の新規学習」が増えていることを確認
9. 「語彙ライブラリ」で学習した語彙を開くと、詳細カードに次回復習日と回答数が表示される
10. 「学習履歴」でグラフと数字が表示され、「苦手な語彙を練習する」でフラッシュカードが始まることを確認
11. 「作文トレーニング」→「お題を決めて書きはじめる」→ 本文を書いて Ctrl+Enter → 自動チェックが表示される →「保存する」で添削依頼文が出る
12. 「これまでの作文」に保存した作文が表示され、「お題の管理」でお題の追加・出題オン/オフができることを確認

## テストの実行

```powershell
pytest
```

テストは一時フォルダに使い捨ての DB を作るので、本物のデータには影響しません。

## データの保存場所

- 語彙データ:`data/vorge.db`(SQLite)。バックアップしたいときはこのファイルをコピーするか、CSV エクスポートを使います。
- 保存場所を変えたい場合は `.env.example` を `.env` にコピーして `VORGE_DB_PATH` を設定します。
- アプリが DB を削除・初期化することはありません。
