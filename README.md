# Vorge — 個人用語彙・言語化トレーニングアプリ

[![test](https://github.com/Sho-itf/Vorge/actions/workflows/test.yml/badge.svg)](https://github.com/Sho-itf/Vorge/actions/workflows/test.yml)

語彙を増やし、考える・説明する・書く・読む・議論する力を鍛えるための個人用学習アプリです。
「覚える → 確かめる → 使う → 振り返る」を 1 つのアプリで回せます。
設計の詳細は [docs/design.md](docs/design.md) を参照してください。

**公開サイト(Web 版・単語カードと語彙ライブラリ):<https://sho-itf.github.io/Vorge/>**
インストール不要で、PC・スマホのブラウザからそのまま使えます。

## できること

**学習**
- **今日の学習(ホーム)**:復習・新しい語彙・クイズ・作文の 1 日のメニューと進み具合。「続きから」で次へ
- **フラッシュカード**:FSRS による復習日の自動設定、4 段階の採点(不正解/自信がない/正解/簡単)、
  「語彙→意味」「意味→語彙」「例文の穴埋め」の 3 モード、答えを入力して確認するモード、間違えた語のもう一度
- **穴埋めクイズ**:例文の空欄に入る語彙を答える(4 択/入力式)。「使い分け」モードでは類義語を選択肢に混ぜる
- **作文トレーニング**:お題・文字数・使う語彙を選んで書き、自動チェック(語彙の使用・繰り返し・文末)と添削依頼文
- **議論トレーニング**:型に沿って主張・根拠・反論・再反論を組み立てる。立場の入れ替え、つなぎ言葉・具体例のチェック
- **読解トレーニング**:読んだ文章の登録済み語彙に印を付け、未登録の語を拾って登録。要約の練習

**記録・データ**
- **学習履歴**:連続日数、正答率、日ごとの回答数、習得状況、苦手な語彙(カードとクイズを合わせて判定)
- **語彙ライブラリ**:検索・一覧(ふりがな付き)・詳細(学習の記録、類義語のリンク、使い分けの比較、辞書リンク)
- **データ管理**:CSV の取り込み・書き出し、自動/手動バックアップと復元、全データの書き出し、ゴミ箱
- **設定**:1 日の始まりの時刻(初期値 朝 4 時)、1 日の目標、スマホから開くためのアドレス

**操作**
- キーボード:フラッシュカードは Space で答えを見る・1〜4 で採点、クイズは 1〜4 で選択・Enter で次へ
- ライト/ダークモード(OS の設定に合わせる)、スマホの幅にも対応

## はじめての準備(初回のみ)

PowerShell でこのフォルダを開いて実行します。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

> `Activate.ps1` が「スクリプトの実行が無効」と言われたら、
> `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` を一度だけ実行してください。

開発(テスト・コードチェック)もする場合は `pip install -r requirements-dev.txt` を使います。

## 起動方法

```powershell
.\.venv\Scripts\Activate.ps1
streamlit run app.py
```

ブラウザで http://localhost:8501 が開きます。終了はターミナルで `Ctrl + C`。
初めて使うときは「データ管理」で同梱のサンプル語彙(`csv/vorge_vocab_seed.csv`)を取り込めます。

### スマホ・タブレットから使う

PC で起動している間は、同じ Wi-Fi のスマホのブラウザから開けます。アドレスは「設定」画面に表示されます
(例:`http://192.168.1.10:8501`)。開けないときは、Windows のファイアウォールで Python の通信を
「プライベート ネットワーク」で許可してください。外出先からは開けません。

## Web 版(単語カードと語彙ライブラリだけ)

PC を起動していなくてもスマホなどから使えるよう、`web/` に**サーバー不要の Web 版**があります。
GitHub Pages で公開していて、<https://sho-itf.github.io/Vorge/> からいつでも開けます。

- できること:ホーム(今日の学習と 1 日の目標・連続学習日数・今日の一語・習得状況・バックアップの注意)、
  単語カード(語彙 → 意味 / 意味 → 語彙 / 例文の穴埋め、入力式、4 段階の採点、FSRS)と語彙ライブラリ(検索・絞り込み・詳細)。
  作文・議論・読解・穴埋めクイズなどは Streamlit 版だけです。
- 語彙:`csv/*.csv` をビルド時に `vocab.json` に変換して配信します。CSV を足して main に push すると自動で反映されます。
  学習記録は「語#番号」(例:`俯瞰#1`)で語彙と結びつくので、CSV の語を書き換えるとその語の記録は引き継がれません。
- 学習の記録:**そのブラウザの中(localStorage)だけ**に保存します。PC とスマホの記録は別々なので、
  「記録」画面の「書き出し」→ もう一方で「取り込み」で引っ越してください。Streamlit 版の記録とは共有しません。
- ホーム画面に追加すると、アプリのように開けます(一度開いたあとは通信できなくても使えます)。

### 手元で動かす(Node.js 24 が必要)

```powershell
cd web
npm install
npm run dev     # http://localhost:5173 で開く
npm test        # テスト(vitest)
npm run build   # 公開用のファイルを web/dist に作る
```

### GitHub Pages で公開する

このリポジトリでは設定済みで、main に push すると自動で更新されます。
自分のリポジトリ(fork など)で公開したい場合の手順は次のとおりです。

1. GitHub のリポジトリ → Settings → Pages → Source を「**GitHub Actions**」にする。
2. main に push すると `.github/workflows/pages.yml` がビルドして公開します(Actions タブの「pages」で進み具合を確認)。

> **注意**:GitHub Pages のサイトは誰でも見られます。`csv/` の語彙・例文はすべて公開されます。
> 学習の記録(各自のブラウザ内)と `data/`(Streamlit 版の DB)は公開物に含まれません。
> また、無料プランで Pages を使うにはリポジトリを公開(Public)にする必要があります(非公開のままなら GitHub Pro が必要)。

## テストとコードチェック

```powershell
pytest
ruff check .
```

- テストは一時フォルダに使い捨ての DB を作るので、本物のデータには影響しません。
- `tests/test_views.py` は Streamlit の AppTest で実際に画面を動かすテストです。
- GitHub に push すると、GitHub Actions が同じテストとチェックを自動で実行します。

## データの保存場所と安全

- 全データ:`data/vorge.db`(SQLite)。保存場所を変えたい場合は `.env.example` を `.env` にコピーして `VORGE_DB_PATH` を設定します。
- バックアップ:アプリを開くと 1 日 1 回 `data/backups/` に自動でコピーします(直近 14 日分)。
  DB の構造を新しくするとき(アプリの更新後)も、その前に自動でバックアップします。
- 削除した語彙・作文はゴミ箱に入り、自分で空にするまで元に戻せます。
- アプリが DB を勝手に初期化することはありません。
